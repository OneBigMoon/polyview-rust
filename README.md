# PolyView

A self-hosted streaming hub that runs on your own NAS — serving your personal
media library with live TV playback, an on-demand catalog, and episode-tracking
for ongoing series, all through a clean, TV-friendly web interface.

> Built for the [Kiroween 2026](https://kiroween.devpost.com/) hackathon
> (Resurrection category): giving idle NAS hardware a second life instead of
> letting it gather dust.

## Planned Features

- **Live TV** — IPTV-style channel playback with a channel guide
- **On-demand catalog** — browse and play your personal media library
- **Episode tracking** — subscribe to ongoing series and track watched episodes
- **Download jobs** — queue and manage library downloads
- **Multi-user** — simple account system with per-user favorites and progress

## Tech Stack

- Rust backend (in development)
- SQLite for local persistence
- TV-friendly web frontend

## Development

This project is being developed with [Kiro](https://kiro.dev/) using
spec-driven development, agent hooks, and MCP integrations.
